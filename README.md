# familystream : versions

Versions de Nuvio TV préparées pour la famille. **Ce n'est pas une version officielle de Nuvio.**

Chaque version contient :

- l'application pour TV et boîtiers Android : `arm64-v8a` (Shield et la plupart des appareils récents) ou `armeabi-v7a` (appareils 32 bits) ;
- le code source correspondant (`familystream-<version>-source.tar.gz`).

Une fois installée, l'application propose elle-même les nouvelles versions au démarrage.
